Farming Simulator（FS2011〜FS25）用の MOD マネージャー。Windows 10・11 対応。

Farming Simulator の弱点は、MOD フォルダーが 1 つしかないことです。そこには多くのマップや、ときには互いに相性の悪い MOD がたまっていきます。ゲーム構成を切り替えるのが面倒なため、新しいマップを試す気になれません。

FS Passion の中心は、この問題を驚くほど効率よく解決することです。数クリックで MOD の集まりである **構成** を作り、ワンクリックで切り替えられます。すべての MOD は元のフォルダー（Mods フォルダー）に 1 つだけ置かれたままです。

- **構成**：マップ、その依存 MOD、選んだ MOD。すべての構成で共有する **共通 MOD**。
- **アップデート**：ゲームが行った更新（ModHub）を取り込み、すべての構成に反映します。置き換えられたバージョンは削除せず、別に保管します。
- **ダウンロード**：新しい MOD を検出し、対応するゲームバージョンの MOD フォルダーに移動します。
- **複数ドライブ**：異なるドライブ上の MOD フォルダーを最大 3 つまで。
- **設定のバックアップ**：構成と設定のエクスポート・インポート。再インストールや別の PC に。
- **ガイドツアー**：ヘッダーの電球が、アニメーション付きの例（バージョン、構成、リスト、複数選択、ドラッグ＆ドロップ、キーボードショートカット）で 1 分で画面を紹介します。
- **FS Passion の使用をやめる**：ゲームは元の設定に戻り、構成フォルダーは削除されます。MOD 自体には一切手を触れません。
- 2 色の **テーマ** と、人気テーマに着想を得たダーク・ライトのテーマ（Catppuccin, Nord, Solarized, Monokai Pro, Gruvbox, Dracula, Tokyo Night, Synthwave '84）。
- **言語**：インターフェースは 14 言語に対応（English, Français, Deutsch, Español, Italiano, Português (Brasil), Português (Portugal), Nederlands, Polski, Čeština, Dansk, Suomi, Norsk bokmål, Svenska）。Windows の言語に合わせて選ばれ、設定で変更できます。独自の翻訳を追加することもできます。 **近日対応: さらに 12 言語**: Magyar, Română, Русский, Українська, Türkçe, Tiếng Việt, Bahasa Indonesia, Español (Latinoamérica), 日本語, 한국어, 简体中文, 繁體中文.
- **デモ**：このアプリは Farming Simulator シリーズの所有者向けです。ゲームを持っていなくても機能を試したい方のために、設定にデモパックがあります。

> ⚠️ 開発中のプロジェクトです（バージョン：[Releases](https://github.com/Michel-MichelMichel/FSPassion/releases) ページを参照）。試す前に MOD フォルダーを完全にバックアップしてください。公式のダウンロード先はこの GitHub ページだけです。

## ダウンロード

[Releases](https://github.com/Michel-MichelMichel/FSPassion/releases) ページから：

- `FSPassion-X.Y.Z-setup.exe`: インストーラー。管理者権限なしで現在のユーザーに、またはすべてのユーザーにインストールできます。必要に応じて Microsoft Edge WebView2 をインストールします（Windows 10）。
- `FSPassion-X.Y.Z-portable.zip`: ポータブル版。インストール不要で、設定とログは `FSPassion.exe` の隣の `data` フォルダーに保存されます。
- `SHA256SUMS.txt`: 2 つのファイルのチェックサム。

ファイルにはまだ署名がありません。初回起動時に Windows SmartScreen が警告を表示することがあります。詳細情報を開き、そのまま実行を選んでください。 SignPath Foundation による無償の署名は、最初のリリースの後に予定されています。

## 翻訳の改善にご協力ください

翻訳はまだ最初の版です。ネイティブスピーカーによる修正を大歓迎します。現在の言語も、これから追加される言語も対象です。プログラミングの知識は不要で、テキストエディター（メモ帳で十分）があれば作業できます。

1. このリポジトリの [`lang`](../lang/) フォルダーを開き、自分の言語のファイル（`ja.json`）をダウンロードします。まだない場合は `en.json` をダウンロードします。
2. FS Passion のインストールにある個人用言語フォルダーにファイルを置きます（Settings → Display → Language の **Open the personal languages folder** ボタンで開けます）。
   - インストール版：`%APPDATA%\FSPassion\lang\`
   - ポータブル版：`FSPassion.exe` の隣の `data\lang\`
3. ファイル名を変更します。例：`ja_corrected.json`（名前を `_` で始めないでください）。ファイル先頭の `"code"` 行は変更しないでください。そうすれば、このファイルが内蔵の言語を置き換えます。`en.json` から始める場合は、`"code"` 行に `"ja"`、`"name"` 行に `"日本語"` と書きます。
4. `:` の右側にある引用符内のテキストを修正し、ファイルを保存します（文字コード UTF-8）。左側のキーと、`{count}` のような波かっこ内の語は変更しないでください。
5. FS Passion を再起動し、Settings → Display → Language で自分の言語を選びます。言語には「personal」と表示されます。画面で修正内容を確認してください。
6. 修正したファイルを [Issues](https://github.com/Michel-MichelMichel/FSPassion/issues) タブから送ってください。「Translation: 日本語」のようなタイトルで issue を作成し、ファイルを添付します（GitHub が `.json` 拡張子を受け付けない場合は ZIP に圧縮してください）。

## インターネット接続

FS Passion が接続するのは GitHub だけで、DLC カタログ（名前とアイコン、公開リポジトリ `FSPassion-data`）を 1 日に最大 1 回読み込みます。個人データは送信されません。「Internet connection」設定（Settings → Application）でオフにできます。また、起動するたびに（その後は 1 日 1 回）GitHub で FS Passion の新しいバージョンを確認します。「FS Passion updates」設定（Settings → Application）でオフにできます。
