Farming Simulator(FS2011~FS25)용 모드 관리자, Windows 10 및 11용.

Farming Simulator의 단점은 모드 폴더가 하나뿐이라는 것입니다. 그 안에 수많은 맵과 때로는 서로 호환되지 않는 모드가 쌓입니다. 게임 구성을 바꾸는 일이 너무 번거로워 새로운 맵을 시도하기가 망설여집니다.

FS Passion의 핵심은 이 문제를 놀라울 만큼 효율적으로 해결하는 것입니다. 몇 번의 클릭으로 모드 모음인 **구성**을 만들고, 한 번의 클릭으로 서로 전환하세요. 모든 모드는 원래 폴더인 Mods 폴더에 하나씩만 남습니다.

- **구성**: 맵, 그 의존성, 그리고 원하는 모드; 모든 구성이 함께 쓰는 **공통 모드**.
- **업데이트**: 게임이 수행한 업데이트(ModHub)를 가져와 모든 구성에 반영합니다. 교체된 버전은 지우지 않고 따로 보관합니다.
- **다운로드**: 새 모드를 감지하여 해당 게임 버전의 모드 폴더로 옮깁니다.
- **여러 드라이브**: 서로 다른 드라이브에 최대 세 개의 모드 폴더.
- **설정 백업**: 재설치나 다른 PC를 위해 구성과 설정을 내보내고 가져옵니다.
- **가이드 투어**: 헤더의 전구가 애니메이션 예시(버전, 구성, 목록, 다중 선택, 끌어서 놓기, 단축키)로 1분 만에 인터페이스를 소개합니다.
- **FS Passion 사용 중지**: 게임이 원래 설정으로 돌아가고 구성 폴더가 제거됩니다. 모드는 절대 건드리지 않습니다.
- 2색 **테마**와 인기 테마에서 영감을 받은 다크·라이트 테마(Catppuccin, Nord, Solarized, Monokai Pro, Gruvbox, Dracula, Tokyo Night, Synthwave '84).
- **언어**: 인터페이스는 14개 언어를 지원합니다(English, Français, Deutsch, Español, Italiano, Português (Brasil), Português (Portugal), Nederlands, Polski, Čeština, Dansk, Suomi, Norsk bokmål, Svenska). Windows 언어에 따라 선택되며 설정에서 바꿀 수 있고, 직접 번역을 추가할 수도 있습니다. **곧 추가: 12개 언어 더**: Magyar, Română, Русский, Українська, Türkçe, Tiếng Việt, Bahasa Indonesia, Español (Latinoamérica), 日本語, 한국어, 简体中文, 繁體中文.
- **데모**: 이 앱은 Farming Simulator 게임 소유자만을 위한 것입니다. 게임 없이 기능을 체험해 보고 싶다면 설정에서 데모 팩을 이용할 수 있습니다.

## 다운로드

[Releases](https://github.com/Michel-MichelMichel/FSPassion/releases) 페이지에서:

- `FSPassion-X.Y.Z-setup.exe`: 설치 프로그램 — 관리자 권한 없이 현재 사용자용으로, 또는 모든 사용자용으로 설치합니다. 필요하면 Microsoft Edge WebView2를 설치합니다(Windows 10).
- `FSPassion-X.Y.Z-portable.zip`: 포터블 버전 — 설치가 필요 없으며, 설정과 로그는 `FSPassion.exe` 옆의 `data` 폴더에 저장됩니다.
- `SHA256SUMS.txt`: 두 파일의 체크섬.

파일은 아직 서명되지 않았습니다. 처음 실행할 때 Windows SmartScreen이 경고를 표시할 수 있습니다. 추가 정보를 열고 그래도 실행을 선택하세요. SignPath Foundation의 무료 서명은 첫 번째 릴리스 이후에 예정되어 있습니다.
